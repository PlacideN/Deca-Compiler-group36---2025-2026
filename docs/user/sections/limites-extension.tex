\section{Limitations de l'extension}
\noindent
L'extension mathématique est soumise à des contraintes de précision liées aux séries de Taylor utilisées en interne et à la précision limitée sur 32 bits :

\begin{itemize}[label=$\circ$]
    \item Les fonctions trigonométriques garantissent une précision de moins d'un ulp pour des valeurs d'entrée standards. Les erreurs s'accumulent pour des valeurs tendant vers l'infini.
    \item Un appel à \texttt{asin} avec un paramètre hors de son domainde de définition ($[-1, 1]$) retournera \texttt{NaN}.
\end{itemize}
