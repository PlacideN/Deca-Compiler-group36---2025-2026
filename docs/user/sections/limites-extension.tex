\section{Limitations des Extensions}
Les extensions mathématiques sont soumises à des contraintes de précision liées à l'algorithme CORDIC ou aux séries de Taylor utilisées en interne :

\begin{itemize}[label=\textbullet]
    \item \textbf{Extension TRIGO :} Les fonctions trigonométriques garantissent une précision jusqu'à $10^{-7}$ pour des valeurs d'entrée standards. Les erreurs s'accumulent pour des valeurs tendant vers l'infini.
    \item \textbf{Domaine de définition :} Un appel à \texttt{asin} ou \texttt{acos} avec un paramètre hors de $[-1, 1]$ provoquera une erreur d'exécution ou retournera \texttt{NaN} selon la configuration.
\end{itemize}
