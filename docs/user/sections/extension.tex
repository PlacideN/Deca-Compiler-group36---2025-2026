\section{Extensions de la Bibliothèque Standard}
Le compilateur intègre une extension permettant l'utilisation de fonctions mathématiques natives via la classe \texttt{Math} (ou via inclusion d'un fichier header \texttt{Math.decah}).

\begin{itemize}[label=\textbullet]
    \item Fonctions trigonométriques : \texttt{sin}, \texttt{cos}, \texttt{asin}, \texttt{acos}, \texttt{atan}.
    \item Fonction ulp : \texttt{ulp}.
\end{itemize}
