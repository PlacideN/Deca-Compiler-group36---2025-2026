\begin{abstract}
\begin{center}
Ce manuel présente le mode opératoire du compilateur \texttt{decac}, conçu pour les utilisateurs ayant une connaissance des spécifications du langage Deca, qui souhaitent l'utiliser avec la bibliothèque \texttt{Math.h}. Il détaille les étapes d'installation, d'utilisation, ainsi que les limitations actuelles du compilateur et de l'extension.
\end{center}
